# Contributing to pybnafar

We welcome contributions from researchers, data scientists, and health professionals!

## How to Contribute
1. **Report Bugs**: Use GitHub Issues to report inconsistencies in data processing.
2. **Suggest Analytics**: If you have a mathematical model for pharmaceutical assistance, open a PR.
3. **Improve Documentation**: Help us make the data dictionary clearer for non-programmers.

## Development Workflow
1. Fork the repository.
2. Install dependencies: `pip install -e .[test]`
3. Run tests before submitting: `pytest tests/`

## Ethical Commitment
As this library deals with public health data, all contributors must ensure that analytical functions do not induce bias or unfair judgment of public health managers without proper statistical foundation.
