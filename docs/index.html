pybnafar 🇧🇷

Inovação e Inteligência de Dados para a Assistência Farmacêutica no Brasil

🚀 O que é?

O pybnafar é um SDK de alto desempenho desenvolvido para facilitar o acesso, processamento e análise da Base Nacional de Dados de Ações e Serviços da Assistência Farmacêutica (BNAFAR) do OpenDATASUS.

🏆 Funcionalidades Chave

  • Detecção de Rupturas: Identifica faltas de medicamentos automaticamente.
  • Risco de Desperdício: Monitora prazos de validade e impacto financeiro.
  • Interoperabilidade RNDS: Exporta dados no padrão HL7 FHIR.
  • Score de Confiança: Avalia a qualidade dos dados municipais de forma ética.

💻 Instalação Rápida

pip install pybnafar

Ou via Docker:

docker run -p 8501:8501 fabianomenegidio/pybnafar
